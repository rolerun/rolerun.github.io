# rolerun.github.io

Página web de Pokémon RoleRun: el formato explicado a fondo y la descarga de
RoleRun Manager. Se publica sola en https://rolerun.github.io/ al subir
cambios a `main`.

El programa vive en [dtimper/rolerun-manager](https://github.com/dtimper/rolerun-manager).
El botón de descarga lee la última versión publicada allí
(`/releases/latest/download/RoleRunManager-Setup.exe` y la API de GitHub),
así que publicar una versión nueva no obliga a tocar esta web.

Es HTML, CSS y JavaScript sin compilar: `index.html`, `styles.css`, `app.js`
y `assets/`. `.nojekyll` evita que GitHub Pages la procese con Jekyll.
